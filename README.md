# Beggar Prince ROM Lab · 《新乞丐王子》MD 逆向改造工具箱

> 世嘉 Mega Drive 游戏《新乞丐王子》(Beggar Prince, 台湾 C&E 1996) 的
> 本地逆向改造研究：升级表定位、武器档位修复、魔法伤害/命中改造。
> **本仓库不包含、也不分发任何 ROM 文件**，只提供分析工具、补丁脚本与 IPS 差量补丁。

## 目录结构

```
rom_toolkit/   跨游戏通用 ROM 逆向工具箱（探壳 / 指纹定位 / 交叉引用 / 参数化补丁）
analysis/      本项目专用分析脚本（升级表、武器表、魔法系统、IPS 生成）
patches/       IPS 补丁文件（只含改动字节，需自备原版 ROM 应用）
plans/         JSON 驱动的补丁配置（魔法秒杀 / 必中）
docs/          逆向过程技术说明文档
evidence/      反汇编证据片段（伤害例程 / 命中判定 / 分派点等）
```

## 方法论：四步撬开老游戏

1. **拿攻略数值当指纹** —— 逐级经验值序列是独一无二的搜索指纹
2. **在文件里反查定位** —— 暴力枚举 起始偏移 × 步长 × 字段编码
3. **反汇编确认语义** —— capstone M68K 确认"谁在读这张表、怎么用"
4. **查引用范围确认安全** —— 确认改动只影响目标系统（如分摊系数表全 ROM 仅 1 条指令引用）

详见 `rom_toolkit/START_HERE.md` 与 `docs/`。

## 关键地址速查（新乞丐王子）

| 表 | 地址 | 说明 |
|---|---|---|
| 升级表 | `0x4043A` | 28 级 × 6B：HP / MP / 升级所需经验 |
| 武器档位表 | `0x3FEE0` | 24 档 × 10B，+2 word 攻击力（原版末档有断崖 bug） |
| 魔法表 | `0x401FA` | 36 条 × 16B |
| 分摊系数表 | `0x3D578` | 6 × f32BE，全 ROM 唯一引用 `$D1640` → 魔法秒杀开关 |
| 命中判定 | `$0D110C` | `0xD1213`、`0xD126C` 改 `7F` 即必中（只影响玩家） |

## 应用补丁（IPS）

1. 自备你合法持有的原版 ROM（校验 MD5 = `cda1c5fa4cd72c9188a228b11150440b`）
2. 用任意 IPS 补丁工具应用（如 [ROM Patcher JS](https://www.romhacking.net/patchers/) 网页工具、Floating IPS 等）
3. 应用后文件仍为 4,194,304 字节

⚠️ 补丁基于汉化版 ROM 制作，请确认你的 ROM 校验值一致，否则会打偏。
